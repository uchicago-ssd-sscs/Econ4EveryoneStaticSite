The Big Picture

Sellers face one problem, how much should I make? Answering it takes three parts, and each part builds on the one before it.

Production. How much extra output does each new worker add?
Costs. What does it cost to make each extra unit?
Revenue and profit. Does the next unit bring in enough to be worth making?

You will review each part with the Fluxuron Factory, then use all three to help a mug studio decide how much to make.

Apply It to Iris's Mug Studio

A new business, the same three parts.

Iris runs a small studio that makes handmade mugs. She has one kiln and a shared studio space, which together cost $24 per day no matter how many mugs she makes. She can hire workers for $12 per day each. Every mug sells for $5.

Because there is only one kiln, adding workers will not work the way Iris first expects. Help her figure out how many mugs to make.
